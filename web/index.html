Set up the engine

M3 Studio runs MiniMax Music 3 on your machine through ComfyUI. The first run installs ComfyUI (or uses one you already have — YuE Studio's works) and downloads about 12 GB of model files, then starts on its own every time after.

Missing Python, Git or ffmpeg? The Engine page installs them for you — a new Python needs M3 Studio restarted before it is picked up.

Where the engine lives and how it starts.

Where models are downloaded to and loaded from. Point it anywhere — a ComfyUI M3 Studio starts is told to read it. A ComfyUI you start yourself is not, so set the same folder there too.

Song writer optional

A chat model that writes the caption, lyrics and title from a line about the song. Ollama and LM Studio run on this computer and need no key; cloud services do. A local writer shares the graphics card with Music 3 — on an 8 GB card a small model (3–4B) is plenty, and Ollama is told to unload after each write. Unload a model you loaded by hand in LM Studio before making songs.
